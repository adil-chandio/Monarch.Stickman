## The physics (not faked)
`generate_video_v3.py` runs a tiny simulator at 1 m = 268 px:

* projectile `h(t) = v₀t − ½gt²`, `g = 9.81 m/s²` (`GRAV = 9.81 * PPM`)
* jump height `h = v₀²/2g` → doubling speed = 4× height (shown on screen)
* crate motion integrated at 240 Hz with `a = F/m` and kinetic friction `μg`
* impulses `J = Δp` → recoil velocity `v = J/m`, then friction braking `x = v²/2μg`
* lever energy chain `PE = mgh`, `KE = ½mv²`, launch height `v²/2g`
